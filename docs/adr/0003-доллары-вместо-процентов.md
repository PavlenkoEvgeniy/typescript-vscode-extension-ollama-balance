# Показываем остаток в долларах, а проценты оставляем фолбэком

ADR-0001 выбрал проценты не по предпочтению, а от безысходности: ни один API ollama.com не отдавал денежный остаток. Это перестало быть правдой — документированный `GET /api/balance` возвращает `included.balance_usd` и `included.allowance_usd`, то есть деньги в явном виде, а не оценку «лимит плана × остаток», которую ADR-0001 справедливо забраковал. Решение: показывать доллары, когда ветвь с балансом доступна, и проценты — только на legacy-планах, где API отдаёт одну лишь долю (`remaining_percent`), денег физически не возвращая. Проценты становятся не вторым вариантом отображения, а честным фолбэком для ветви, у которой нет другого выбора.

## Consequences

- Имя продукта (Ollama Balance) и имя endpoint'а (`/api/balance`) перестают противоречить глоссарию: `Остаток` больше не запрещает доллары.
- Пороги и раскраска остаются процентными — они считаются от `Доли использования`, а не от денег, и потому одинаковы на обеих ветвях.
- Две ветви ответа обязаны жить в одной модели: денежная и процентная различаются по природе, и сводятся они только через `Долю использования`.
