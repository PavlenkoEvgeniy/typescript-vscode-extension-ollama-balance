# Показываем остаток в процентах, а не в долларах

Пользователь просил «показывать остаток баланса», но ни один API ollama.com не отдаёт остаток купленных кредитов («extra usage») — открытый запрос на такой endpoint ([issue #12532](https://github.com/ollama/ollama/issues/12532)) висит давно. Единственные честные числа — доли использования окон (`limits.*.usage`, 0..1). Вариант «считать доллары самим» (лимит плана × остаток) отвергнут: это оценка, которая врёт при смене плана и не применима к Free. Решение: в статус-баре — проценты неиспользованного месячного окна; доллары в v1.0 не показываются нигде.

## Consequences

- Если Ollama добавит официальное поле баланса, расширение можно перевести на него без смены архитектуры (это отдельный ADR).
- Пороговые раскраски тоже процентные: оранжевый при израсходованных ≥50 %, красный при ≥90 %.
